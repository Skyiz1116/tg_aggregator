# Агрегатор корпоративных переписок Telegram

Проект представляет собой Telegram-бота, который собирает сообщения из чатов, сохраняет их в PostgreSQL и позволяет администратору выгружать историю переписки в CSV-формате.

## 🛠 Технологии

- **Python 3.12**
- **aiogram 3.x** — асинхронный фреймворк для Telegram-ботов
- **PostgreSQL 18** — реляционная база данных
- **SQLAlchemy 2.x (psycopg2)** — ORM для работы с БД
- **python-dotenv** — управление переменными окружения
- **pandas** — обработка данных (для будущей аналитики)

## ⚙️ Переменные окружения (.env)

Для работы проекта необходимо создать файл `.env` в корне проекта и заполнить его:

| Поле | Описание | Пример |
|---|---|---|
| `BOT_TOKEN` | Токен Telegram-бота от @BotFather | `1234567890:AAH...ваш_токен...` |
| `ADMIN_IDS` | Telegram ID администраторов через запятую | `123456789, 987654321` |
| `DATABASE_URL` | Строка подключения к PostgreSQL | `postgresql+psycopg2://postgres:ваш_пароль@127.0.0.1:5432/tg_aggregator` |
